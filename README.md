# Encaixe — Estruturas de Dados em Ação

Site educacional com 7 mini-projetos interativos que mostram estruturas de dados funcionando em cenários reais (call stack, escalonamento, grafos, hash, BST, alocação de memória).

Stack: Next.js 14 (App Router, TypeScript strict) no frontend, Django 5 + DRF no backend. Especificação completa em `spec-site-estruturas-de-dados.md`.

## Features

- 7 estruturas de dados puras em Python testadas isoladamente, consumidas por endpoints magros.
- **Modo passo-a-passo** nos projetos de pilha, BST e hash: usuário avança manualmente ou usa autoplay (0.5×/1×/2×) e vê cada push, comparação ou colisão com descrição em linguagem natural.
